# ssTV · 松鼠TV

松鼠TV 是一款支持片源配置、影片搜索、在线播放、观看历史和离线缓存的播放器。

## 项目信息

- 项目名：ssTV
- 应用名：松鼠TV
- 版本：1.0.1（versionCode 25）
- 包名：`com.songshu.sstv`
- 语言：Kotlin
- 最低系统 API：26；编译和目标 API：34
- 构建工具：JDK 17、Gradle 8.7、AGP 8.5.2、Kotlin 1.9.24

## 编译

准备 JDK 17 和 API 34 SDK，在本地 `local.properties` 中配置 `sdk.dir`。

```shell
# Windows
.\gradlew.bat assembleDebug

# macOS / Linux
./gradlew assembleDebug
```

调试包输出至 `app/build/outputs/apk/debug/app-debug.apk`，使用本机调试签名。
详细步骤见《怎么编译成APK.txt》。

## 发布签名

将自己的密钥保存在本地，并在用户目录的 `.gradle/gradle.properties` 中设置：

```properties
SSTV_STORE_FILE=keystore/sstv.jks
SSTV_STORE_PASSWORD=你的密钥库密码
SSTV_KEY_ALIAS=你的密钥别名
SSTV_KEY_PASSWORD=你的密钥密码
```

密钥路径相对于项目根目录，也可使用绝对路径。密钥别名及密码必须与实际密钥一致。
配置完整后运行 `assembleRelease` 生成签名发布包；未配置时生成未签名发布包。
签名文件、本机 SDK 配置和构建产物均不提交到仓库。

## 安装说明

包名已经改为 `com.songshu.sstv`，系统会将松鼠TV视为新应用。
旧应用的设置、观看历史和缓存不会自动迁移。

## 内容来源

播放内容来自用户配置的第三方接口。松鼠TV本身不提供、不存储、不代理影片。

## 外观与体验

找片页的 Top 10 永远使用列表，不会自动弹出键盘。排行先显示本地缓存，十分钟内复用，过期后后台刷新；分页结果先显示已有内容。首页会提前加载排行，和找片页共享请求，避免重复等待。排行使用接口提供的热度与更新时间，缺少热度时保留最新更新顺序。首页、搜索结果、收藏与喜欢默认使用三列网格，保存各自的模式和列数，保留已有明确设置。搜索页「历史」保留最近 15 条去重关键词，可点选搜索、逐条删除或清空。

搜索按片源响应速度分组，组内识别中文和阿拉伯数字季数排序，支持正序、倒序，每页结果到达后重新排序。无季数时按关联度、上映时间排序。完结剧集显示总集数，优先使用片源总集数字段并结合播放列表和备注识别。

下载支持最多八路 HLS 分段并发；支持范围请求、资源校验标记且至少 4 MiB 的直链使用四路分段。每段校验状态、范围和长度后按序合并，不支持或校验失败会回退整文件下载。实际速度取决于网络和片源限制。

播放器支持收藏影片、记录喜欢的时间点。收藏夹可以创建带备注的分组，封面由前四部影片组成；同一片源的影片只能收藏一次。喜欢按影片、集数、时间点逐级查看，点击时间点直接播放。收藏与喜欢均支持列表、网格和 2—8 列。

多集缓存自动归入剧集文件夹，即使只下载一集也会归档；电影单独展示。新缓存记录并显示片源，旧缓存优先从历史补充来源，无法确认时显示「来源未记录」。播放页底部「清空」经确认后会停止播放并删除此影片的相关历史，不影响收藏、喜欢及其他片源历史。设置中的 NSFW 默认关闭，开启后包含成人分类。

默认使用「晴日手帖」。设置页「外观 → 主题风格」提供四种风格，选择后自动保存，返回其他页面也会同步：

- **曜石影院**：深黑朱红、适中圆角，适合沉浸观影。
- **极光漫游**：靛蓝背景、薄荷高亮、大圆角与柔和渐变。
- **晴日手帖**：暖米白、陶土色、衬线字体与小圆角，系统栏同步变浅。
- **像素终端**：墨绿背景、荧光绿、等宽字体与近直角控件。

可开启「减少动画」关闭页面和封面的渐入；也遵循系统动画设置。
设置按播放、外观、片源与内容、缓存与存储、关于分组。片源管理在独立弹窗中完成，可搜索、切换、添加、导入、编辑、检测和删除片源。
首页与搜索页会根据屏幕宽度调整影片列数。首页筛选可展开收起，列表支持滑动分页。
底部导航包含首页、找片、播放、我的。竖屏视频置顶，下面显示选集、换源和影片信息；横屏进入全屏播放。

## 播放与投屏

播放器右下角提供全屏入口，底部提供播放/暂停、下一集、选集与横向倍速标尺。标尺中心固定，拖动预览、松手应用并吸附，不会在拖动中自动拉回。
横屏左侧上下滑调亮度，右侧上下滑调媒体音量；默认显示开锁图标，点击锁定后只保留播放/暂停、退出全屏和解锁，进度拖动及其他手势禁用。
设置中的「播放页保留上次内容」默认开启。从底部导航进入播放页会恢复上次内容和进度，但保持暂停；离开播放页也会暂停。已有手动选择会保留。

投屏支持同一 Wi-Fi 下开启 DLNA/UPnP MediaRenderer 的设备，支持在线视频地址和远程播放、暂停、进度控制。
电视需要能够直接访问该视频地址；本地文件暂不支持投屏。协议已使用模拟设备测试，实际电视兼容性仍需设备联调。

搜索按片源分别显示结果，相同片名保留在各自片源下，按本次搜索响应时间从快到慢排序。
