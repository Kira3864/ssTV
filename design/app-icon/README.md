# 松鼠TV 正式图标

`source.png` 为用户提供的原始图，统一用于 Android 与未来的 Windows 版本。
`sstv.ico` 包含 16、24、32、48、64、128、256 像素，供 Windows 程序、快捷方式及安装包使用。
`sstv.png` 为 512 像素通用资源。

执行 `python design/app-icon/generate.py` 可重新生成 Android 各密度图标和 Windows 资源，需要 Pillow。
Android 自适应图标使用橙色背景与内缩的原图，兼容圆形及圆角遮罩。
不继续使用旧图标的单色图层，以免开启系统主题图标后显示旧松鼠。

Windows 发布要求：同一版本提供安装程序与免安装 ZIP，均包含所需运行库，使用同一图标及功能。
安装版数据放在用户应用数据目录；免安装版默认放在程序目录的 `data/` 中，下载目录可配置。
免安装版需解压到可写目录运行，数据目录不随版本更新覆盖。
Windows 客户端尚待开发；本目录是图标资源，不能作为可运行的 Windows 发布包。
