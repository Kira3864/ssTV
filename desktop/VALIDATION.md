# 0.1 首版验证（2026-10-27）

## 0.1.2 更新验证（2026-10-28）

15 项集成用例通过，进程退出码为 0。新增中央暂停/恢复图标、跨片源查询及切换、HLS 实际档位读取和切换保留进度测试。
弱网测试先正常播放，再将第七个一秒 HLS 分片延迟 10 秒：确认进入缓冲而非用户暂停，随后自动恢复到后续播放位置。
检查了缓冲状态和中央播放图标截图。不能据此保证所有公网片源、网络及显卡都不发生等待。

## 0.1.1 更新验证（2026-10-28）

12 项集成用例通过，进程退出码为 0。新增方向键 → 点按精确快进 5 秒、长按倍速和恢复测试；原有鼠标长按、失焦恢复、全屏、主题、直链续传及离线 HLS 回归通过。
已检查中性深灰播放器截图，包括细进度条、音量条、轻量控制按钮及当前倍速显示。

- MSVC 2022 x64 Release 构建通过；Qt 6.8.3，libmpv e471496c56。
- 11 项 QtTest 用例通过，进程正常退出（包括初始化与清理用例）。
- 验证实际视频解码、右键按住倍速/恢复、移出画面释放、失去焦点及离开页面恢复、空格暂停、跳转、双击全屏且不误暂停、四主题截图。
- 本地 HTTP 测试接口验证直链暂停和带 ETag 的 HTTP 206 续传，完成文件与原文件逐字节一致。
- 本地 HLS 分片下载后成功通过本地播放列表播放。
- 发布版移除 QtTest；在 PATH 无 Qt SDK 的环境下，从 ZIP 解压运行及安装后运行均通过真实视频启动检查。
- 安装测试使用独立测试目录，测试后运行卸载程序。

测试视频为本地生成的 1280×720 / 30 fps H.264 + AAC 测试图。实测可用 d3d11va-copy 硬解路径；不是 D3D 零拷贝。
首次打包测量约 49 MiB 安装 EXE、72 MiB 免安装 ZIP。
播放启动时进程工作集约 317–373 MiB（包括共享页），仅为本机多次启动快照，仍需优化；尚未做长期内存、4K、高刷屏帧耗时、弱网及多显卡覆盖测试。
没有将这次功能测试等同于“所有设备和片源都不卡顿”。

未验证：真实电视 DLNA（功能未迁移）、受保护片源、HDR/多显示器、加密 HLS 的完整矩阵，以及手机版未迁移功能。
