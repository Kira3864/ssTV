三、编译成 APK（命令行，不用装 Android Studio）
  先准备三样：
    ① JDK 17   （注意不是 8、不是 11 —— AGP 8.5 要求 17）
    ② Android SDK：Platform 34 + Build-Tools 34.0.0
    ③ 能上网（第一次编译要下依赖，仓库已经配成阿里云镜像）

  Windows 步骤：
    1. 装好 JDK 17，设好环境变量 JAVA_HOME
    2. 打开 local.properties，把 sdk.dir 改成你自己的 Android SDK 位置，例如：
         sdk.dir=C\:\\Android\\Sdk
       （冒号和反斜杠都要转义，格式就照着原来那行改，只换路径）
    3. 在本目录开一个 cmd 窗口，敲：
         gradlew.bat assembleRelease
       第一次会去下 Gradle 8.7 本体（约 130MB，走华为云镜像，比官方快很多）
    4. 编完，产物在：
         app\build\outputs\apk\release\app-release.apk
       这个 apk 直接装手机就行。

  想编个带日志的调试版：
     gradlew.bat assembleDebug

  用 Android Studio 的话：
     直接 File → Open 选这个文件夹，等 Sync 完，
     菜单 Build → Generate Signed Bundle / APK 也可以。

四、关于签名（重要，别跳过）
  app/build.gradle 里已经写好签名配置，密钥就在 keystore/jingying.jks，
  口令和别名也都写在配置里了。所以：
    · 用这个包编出来的 APK，签名跟你手机里现在装的**完全一致**
    · 可以直接覆盖安装，缓存、历史、设置都不会丢
  ⚠️ keystore/jingying.jks 千万别弄丢、也别外传。
     丢了以后再编的包签名就不一样了，装上去会提示「应用签名不一致」，
     只能卸载重装 —— 缓存全没。

六、这一版（v1.16）能做到什么
    · 30 个实测可用的苹果 CMS 片源，分类 / 搜索 / 播放地址三个环节都验过
    · 搜索、详情、选集、播放、手势（左右滑调进度、双击暂停）、观看历史
    · 缓存下载：分片并发、断点续传、AES-128 加密流、双层 m3u8 自动分流
    · 桌面悬浮窗：退到后台、刷别的 App 也能看见缓存进度。
      标志是一颗蜘蛛 —— 一开始近乎透明，随进度从下往上被淡蓝色填满，
      下完了整只变淡蓝、开始呼吸灯式闪烁；长按可展开成胶囊，看百分比和速度
